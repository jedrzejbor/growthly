# Roadmap

Sprint 0 establishes the development foundation. Later milestones below are proposals. The founder sets priority and approves business rules.

| Milestone                     | Deliverable                                                                     | Exit evidence                                                   |
| ----------------------------- | ------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| Sprint 0 · Foundation         | Application shell, role briefs, local service config and repeatable checks      | Production build and credential-free smoke suite pass           |
| Next · Identity and access    | Approved role matrix, local Supabase authentication and first profile migration | Local sign-in, sign-out, session expiry and RLS isolation tests |
| Discovery                     | Approved listing fields, founder-owned campaigns and public projections         | Publication and visibility tests using local fixtures           |
| Collaboration and attribution | Approved collaboration lifecycle and conversion evidence model                  | Transition, ownership and duplicate-event tests                 |
| Financial sandbox             | Approved commission model and Stripe test-mode event handling                   | Idempotency, rounding and reversal tests with test events       |
| Release preparation           | Operational review, recovery process and market-specific launch decisions       | Explicit founder authorization for release                      |

See the [engineering backlog](docs/BACKLOG.md) for the next assignable work.
